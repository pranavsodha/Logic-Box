Logic Box – Pattern Generator and Number Analyzer

📌 Project Overview

Logic Box is a beginner-friendly Python console project that combines pattern generation and basic number analysis in a single program.

The project provides a menu-driven interface where the user can:

1. Generate a star pattern.
2. Analyze a range of numbers.
3. Exit the program.

This project is designed to practice fundamental Python programming concepts such as input/output, conditional statements, loops, ranges, arithmetic operators, and f-strings.

✨ Features

1. Pattern Generator

- Takes the number of rows from the user.
- Generates a right-angled star pattern.
- Uses nested "for" loops.

Example:

*
**
***
****
*****

2. Number Range Analyzer

- Takes the starting and ending numbers of a range.
- Checks whether each number is Even or Odd.
- Calculates the sum of all numbers in the given range.

Example:

Number 10 is Even.
Number 11 is Odd.
Number 12 is Even.
Number 13 is Odd.
Number 14 is Even.
Number 15 is Odd.

Sum of all numbers from 10 to 15 is: 75

3. Exit Option

- Allows the user to exit the program with a goodbye message.

▶️ How to Run

1. Install Python 3 on your computer.
2. Download or clone this project.
3. Open the project folder in VS Code or any Python IDE.
4. Run the Python file:

python Logic_Box.py

5. Select an option from the menu.
